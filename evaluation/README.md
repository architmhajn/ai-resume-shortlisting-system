# Resume Shortlisting Evaluation Dataset

Add one JSON object per line with:

- resume: resume text
- job_description: job description text
- relevant: true or false human label

Example:

{"resume":"Java Spring Boot developer with SQL experience","job_description":"Backend developer requiring Java, Spring Boot and SQL","relevant":true}
{"resume":"Graphic designer experienced with Photoshop","job_description":"Backend developer requiring Java, Spring Boot and SQL","relevant":false}

Do not use this example as a performance benchmark. Replace it with human-labeled examples before reporting metrics.
